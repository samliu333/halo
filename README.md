# Halo

现货该持有几成，一眼就知道。

Halo 是一个独立的现货仓位助手：只用收盘价，算出建议持仓比例，并和「每月无脑定投」对照。不做合约、不加杠杆、不预测点位。

## 它做什么

- 读取公开行情（BTC、ETH、SOL、BNB、DOGE、XRP）
- 用价格偏离和涨速，给出 0–100% 的建议仓位
- 一键把模拟钱包对齐到建议仓位
- 同一段历史上，对照定投是否真的更好
- 可在设置里搜索一组对照定投更优的节奏（容易过拟合，只作学习）

## 它不做什么

- 不是投资建议
- 不是交易所实盘下单系统
- 历史优化不等于未来会赚

模拟仓位保存在你自己的浏览器里。

## 界面

苹果风格：浅色、大数字、底部四个入口——今日、对照、钱包、设置。
